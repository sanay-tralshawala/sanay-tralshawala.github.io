Semantic Segmentation of Satellite Imagery

Jan – May 2025 · Carnegie Mellon University · Deep Learning

Overview

High-resolution aerial imagery enables automated land-cover mapping at scale — a capability critical for urban planning, environmental monitoring, and disaster response. This project benchmarks three deep learning architectures on the FLAIR-1 dataset, a French aerial imagery benchmark providing 512×512 image patches with five input channels (RGB, near-infrared, elevation) and 19 semantic classes, consolidated here into six broad land-cover categories: built non-vegetated surfaces, bare non-vegetated surfaces, woody vegetation, cultivated land, herbaceous vegetation, and water.

The study addresses three questions: (1) do modern convolutional architectures and self-supervised pretraining improve segmentation over a ResNet34 U-Net baseline; (2) does adding NIR and elevation channels improve RGB-only performance; and (3) what per-class confidence guarantees can the models provide?

Code and full analysis: github.com/sanay-tralshawala/DLE-Flair-Segmentation

My Contributions

This was a collaborative project. My primary responsibilities were: designing and loading the model architectures for all three models; building the data loader for consistent preprocessing across experiments; leading the DINOv3 ConvNeXt-Tiny training runs; and owning the entire conformal prediction analysis — from framing the statistical question to implementation and write-up.

Models & Architecture

Three architectures were compared, all evaluated on the same train/validation/test splits (80/10/10) with mIoU as the primary metric.

ResNet34 U-Net (baseline) — an encoder-decoder with skip connections. The ResNet34 backbone uses residual connections to prevent vanishing gradients; the decoder upsamples back to full resolution. ~24.4M parameters.

ConvNeXt-Tiny — a modernized CNN that borrows design choices from Vision Transformers: larger kernels, depthwise convolutions, inverted bottlenecks, GELU activations, and LayerNorm. The larger receptive field captures broader spatial context for land-cover classes. Initialized from supervised ImageNet pretrained weights. ~31.2M parameters.

DINOv3 ConvNeXt-Tiny — the same ConvNeXt-Tiny architecture, but initialized from Meta's DINOv3 self-supervised weights pretrained on 1.6 billion high-resolution images. A lightweight 2-layer convolutional decoder head maps learned features to the 6-class pixel output. This was the model I led, motivated by testing whether internet-scale self-supervised pretraining produces better generalization under limited fine-tuning data.

Results

DINOv3 ConvNeXt-Tiny achieved the best test mIoU of 0.491 in the 5-channel configuration, outperforming both the ResNet34 U-Net baseline (0.460) and the supervised-pretrained ConvNeXt-Tiny (0.447 on test, despite higher validation mIoU — a sign of overfitting to the toy validation split). This suggests that self-supervised pretraining on internet-scale data provides a meaningful generalization advantage over supervised pretraining, even when the architecture is identical.

The 5-channel ablation showed that adding NIR and elevation improved ConvNeXt-Tiny by +0.037 mIoU and DINOv3 by +0.013, but degraded ResNet34 U-Net by -0.024, pointing to differences in how robustly each backbone integrates newly initialized input channels.

Conformal Prediction & Uncertainty Analysis

To understand model confidence and per-class coverage guarantees, I implemented a conformal prediction analysis. The question: what prediction set size is needed at each pixel so that the true class is included 90% of the time?

The validation set served as the calibration set. Softmax thresholds were computed per model to achieve 90% marginal coverage across the test set. Results revealed that no model reliably meets 90% overall coverage. The Bare (Non-vegetated) class failed severely across all six model configurations (below 50%), consistent with it representing only 4.7% of the dataset. The Built (Non-vegetated) class performed exceptionally well (93–98%), while Water coverage was strong only for DINOv3-based models.

Average prediction set sizes ranged from 1.38–1.52, suggesting low apparent uncertainty — but this is misleading, as high-confidence majority classes dominate the average and mask critical under-coverage in minority classes. This analysis exposed a direct link between class frequency and model confidence that would persist until the full 65GB FLAIR-1 dataset is used for training.

Key Takeaways

The results partially support the hypothesis that modern architectures and self-supervised pretraining improve performance. DINOv3 wins on test generalization; supervised ConvNeXt overfit to the validation split. The toy dataset limits strong conclusions — the immediate next step is training on the full FLAIR-1 dataset with a fully independent conformal calibration set. The conformal prediction work highlighted that low average uncertainty scores can be deeply misleading when class distributions are imbalanced.
